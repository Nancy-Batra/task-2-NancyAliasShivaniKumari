## Order Status Prediction Using K-Nearest Neighbors (KNN) | Python

This project is a machine learning classification task developed using the K-Nearest Neighbors (KNN) algorithm. The project includes data preprocessing, feature scaling, train-test splitting, model evaluation using Accuracy, F1 Score, and a Confusion Matrix for predicting order status. 

#### Dataset:
It uses an order dataset containing information such as product type, quantity, unit price, payment method, order date, coupon code, referral source, and total price to predict the order status.

The dataset is divided into training and testing sets. The KNN algorithm is trained with different values of K (from 1 to 20), and the value producing the highest test accuracy is selected for the final model. The model's performance is evaluated using Accuracy, Weighted F1 Score, and a Confusion Matrix.

#### Key concepts and techniques used:
- Data preprocessing and feature extraction.
- Label Encoding for categorical variables.
- StandardScaler for feature scaling.
- Train-test splitting.
- K-Nearest Neighbors (KNN) classification.
- Selecting K based on accuracy.
- Model evaluation using Accuracy, Weighted F1 Score, and Confusion Matrix.
